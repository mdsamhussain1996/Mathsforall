How ChatGPT Pays Attention

Dot Products, Softmax & Matrix Projections in the Transformer

Consider this sentence: "The animal didn't cross the street because it was too tired." Now change one word: "The animal didn't cross the street because it was too wide." As a human, you immediately know that in sentence one "it" is the animal, but in sentence two "it" is the street. How does a neural network do this in 10 milliseconds using pure linear algebra?

💡 1. The Big Idea

The Core Intuition

Attention is a soft, differentiable dictionary lookup. For every token, the model projects it into three vectors: a Query ("What am I searching for?"), a Key ("What clues do I offer?"), and a Value ("What content do I carry?"). To measure how relevant word B is to word A, the model takes their dot product. Two vectors pointing in the same direction yield a massive positive number; perpendicular vectors yield zero.

📐 2. The Formal Mathematics

The entire self-attention mechanism published in Google's landmark paper "Attention Is All You Need" is expressed in one elegant matrix formula:

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right) V$$

Here is what each component does:

  • $Q K^T$: Pairwise dot product between every query and key token. Measures semantic alignment.
  • $\sqrt{d_k}$ scaling: In high dimensions (e.g. $d_k = 64$), dot products can grow large, pushing softmax into flat saturation zones with near-zero gradients. Dividing by $\sqrt{d_k}$ keeps the variance at exactly 1.
  • $\text{softmax}$: Turns raw similarity scores into probability weights that sum to 1 across the sequence.
  • $\cdot V$: Computes a contextualised blend of all value vectors weighted by attention.
📝 Worked Example by Hand

Let token "it" have query $\mathbf{q} = [2, 1]^T$ ($d_k=2$). It evaluates two candidates: "animal" with key $\mathbf{k}_1 = [3, 2]^T$ and "street" with key $\mathbf{k}_2 = [0, 2]^T$:

Step 1: Compute Raw Dot Products
$$s_1 = \mathbf{q} \cdot \mathbf{k}_1 = (2)(3) + (1)(2) = 6 + 2 = 8$$ $$s_2 = \mathbf{q} \cdot \mathbf{k}_2 = (2)(0) + (1)(2) = 0 + 2 = 2$$
Step 2: Scale by $\sqrt{d_k} = \sqrt{2} \approx 1.414$
$$s_1' = 8 / 1.414 \approx 5.66, \qquad s_2' = 2 / 1.414 \approx 1.41$$
Step 3: Apply Softmax
$$e^{5.66} \approx 287.15, \quad e^{1.41} \approx 4.10, \quad \sum = 291.25$$ $$\alpha_1 = \frac{287.15}{291.25} = 0.986 \;(98.6\%), \qquad \alpha_2 = \frac{4.10}{291.25} = 0.014 \;(1.4\%)$$ Conclusion: Token "it" focuses 98.6% of its attention on "animal" and only 1.4% on "street"!

🐍 4. Try It in Python (< 15 Lines)

Python 3 Runnable Snippet
import numpy as np

def softmax(x):
    e = np.exp(x - np.max(x, axis=-1, keepdims=True))
    return e / e.sum(axis=-1, keepdims=True)

# 3 tokens (e.g. ["animal", "street", "it"]), d_k = 2
Q = np.array([[0.8, 0.4]])           # Query for "it"
K = np.array([[0.85, 0.4], [-0.8, 0.7], [0.5, 0.5]]) # Keys
V = np.array([[1.0, 0.0], [0.0, 1.0], [0.5, 0.5]])  # Values

scores = (Q @ K.T) / np.sqrt(K.shape[1])
weights = softmax(scores)
context = weights @ V

print("Attention weights:", np.round(weights, 3))
print("Output Context vector:", np.round(context, 3))
