How WhatsApp Keeps Secrets

Modular Arithmetic, One-Way Functions & End-to-End Encryption

When you send a private message on WhatsApp, it travels through airport coffee-shop Wi-Fi, internet service providers, undersea telecom cables, and government servers. Anyone tapping those cables can read every byte. How can your phone and your friend's phone establish an unbreakable secret key across an open, hostile room without ever whispering the key?

💡 1. The Big Idea

The Core Intuition

Cryptography relies on mathematical one-way doors (trapdoor functions). Mixing yellow and blue paint to make green paint is easy; but if someone gives you a bucket of green paint, separating it back into pure yellow and blue is virtually impossible. In modular arithmetic, multiplying and exponentiating numbers modulo a prime is lightning-fast forward, but running it backwards (the Discrete Logarithm Problem) would take all the supercomputers on Earth billions of years.

📐 2. The Formal Mathematics

The core protocol that powers secure messaging is the Diffie-Hellman Key Exchange (built on modular arithmetic):

$$\text{Public Agreement: Prime } p, \; \text{Generator Base } g$$ $$\text{Alice chooses secret } a \implies \text{Sends public } A = g^a \bmod p$$ $$\text{Bob chooses secret } b \implies \text{Sends public } B = g^b \bmod p$$ $$\text{Alice calculates: } K = B^a = (g^b)^a \equiv g^{ab} \bmod p$$ $$\text{Bob calculates: } K = A^b = (g^a)^b \equiv g^{ab} \bmod p$$

Both phones now share the exact same symmetric key $K = g^{ab} \bmod p$! An eavesdropper watching the network sees $g, p, A,$ and $B$, but cannot compute $g^{ab}$ without solving the discrete logarithm to find $a$ or $b$.

📝 Worked Example by Hand

Let's run Diffie-Hellman with small numbers: public prime $p = 23$ and generator $g = 5$:

Step 1: Alice and Bob Pick Secrets
Alice chooses private $a = 6$. Bob chooses private $b = 15$.
Step 2: Compute and Exchange Public Keys Over the Wire
Alice sends $A = 5^6 \bmod 23 = 15625 \bmod 23 = 8$.
Bob sends $B = 5^{15} \bmod 23 = 19$.
Step 3: Compute the Shared Secret Key
Alice computes $K = B^a \bmod 23 = 19^6 \bmod 23 = 2$.
Bob computes $K = A^b \bmod 23 = 8^{15} \bmod 23 = 2$.
Conclusion: Both phones independently reach the secret key $K = 2$! An attacker with access to $A=8, B=19$ is completely locked out.

🐍 4. Try It in Python (< 15 Lines)

Python 3 Runnable Snippet
p = 23  # Prime modulus
g = 5   # Generator

# Alice
a = 6
A = pow(g, a, p) # Alice public key (8)

# Bob
b = 15
B = pow(g, b, p) # Bob public key (19)

# Shared Key computation (O(log exp) time)
alice_shared = pow(B, a, p)
bob_shared = pow(A, b, p)

print(f"Alice key: {alice_shared}, Bob key: {bob_shared}, Match: {alice_shared == bob_shared}")
