How Google Ranked the Web

Eigenvectors, Random Surfers & the $1 Trillion Linear Algebra Algorithm

How did Google figure out which of 50 billion web pages to show you in 0.2 seconds? In 1996, search engines just counted keyword matches—so spam sites simply typed "cheap shoes" 10,000 times in invisible white font. Larry Page and Sergey Brin had a radical intuition: what if links weren't just hyperlinks, but votes of confidence from one human creator to another?

💡 1. The Big Idea

The Core Intuition

A link from the New York Times is worth millions of links from random spam blogs. In other words: a page is important if important pages link to it. That sounds like a circular definition! How do you compute who is important if you need to know who is important first? In mathematics, circular definitions are solved using equilibrium distributions and eigenvectors.

📐 2. The Formal Mathematics

Model the entire internet as a directed graph where pages are nodes and links are edges. If page $i$ has $C(i)$ outgoing links, each receiving page gets a vote fraction of $1/C(i)$. The rank of page $j$ is:

$$r_j = \sum_{i \in \text{links to } j} \frac{r_i}{C(i)}$$

In matrix notation: $\mathbf{r} = M \mathbf{r}$. But what if a page has no outbound links (a dead end) or groups of pages trap the surfer? Page and Brin introduced a damping factor $d = 0.85$: with 85% probability the surfer clicks a link on the current page; with 15% probability they get bored and teleport to any random page across the entire web:

$$G = d M + \frac{1-d}{n} \mathbf{1}\mathbf{1}^T, \qquad G \mathbf{r} = 1 \cdot \mathbf{r}$$

Notice that equation: $G \mathbf{r} = 1 \cdot \mathbf{r}$. PageRank is literally finding the principal eigenvector of the Google transition matrix $G$ with eigenvalue $\lambda = 1$! By the Perron-Frobenius theorem, this equilibrium vector is guaranteed to exist and be unique.

📝 Worked Example by Hand

Consider a mini-internet of 3 pages: A links to B and C; B links to C; C links to A. Let damping $d=1$ for hand calculation:

Step 1: Set up the Column-Stochastic Transition Matrix $M$
Page A distributes its weight 50/50 to B and C. Page B sends 100% to C. Page C sends 100% to A: $$M = \begin{bmatrix} 0 & 0 & 1 \\ 0.5 & 0 & 0 \\ 0.5 & 1 & 0 \end{bmatrix}$$
Step 2: Solve the Linear System $(M - I)\mathbf{r} = \mathbf{0}$
$$\begin{aligned} r_A &= r_C \\ r_B &= 0.5 r_A \\ r_C &= 0.5 r_A + r_B = 0.5 r_A + 0.5 r_A = r_A \end{aligned}$$
Step 3: Normalise so probabilities sum to 1 ($r_A + r_B + r_C = 1$)
$$r_A + 0.5 r_A + r_A = 1 \implies 2.5 r_A = 1 \implies r_A = 0.4, \quad r_B = 0.2, \quad r_C = 0.4$$ Conclusion: Pages A and C tie for #1 rank (40% each), while Page B gets 20%. Page C receives votes from both A and B, making it high authority!

🐍 4. Try It in Python (< 15 Lines)

Python 3 Runnable Snippet
import numpy as np

# Transition matrix: columns sum to 1
M = np.array([
    [0.0, 0.0, 1.0],
    [0.5, 0.0, 0.0],
    [0.5, 1.0, 0.0]
])
d, n = 0.85, 3
G = d * M + (1 - d) / n * np.ones((n, n))

# Power Iteration: simulate infinite surfing
r = np.ones(n) / n
for _ in range(50):
    r = G @ r

print("PageRank scores:", np.round(r, 4))
# Output: [0.3878, 0.2148, 0.3974] -> Page C ranks highest!
